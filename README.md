
# 🧮 Python Calculator

A simple command-line calculator built using Python. This project performs basic arithmetic operations and includes input validation and error handling.

## 📌 Project Overview

The Python Calculator allows users to perform:

- Addition
- Subtraction
- Multiplication
- Division
- Exit the program

The calculator continues running until the user chooses the Exit option.

## 🛠️ Technologies Used

- Python 3
- VS Code / Google Colab

## ✨ Features

- User-friendly menu
- Addition, subtraction, multiplication and division
- Handles invalid menu choices
- Prevents division by zero
- Handles invalid numeric input
- Continuous calculation using a loop

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any Python-supported environment.
3. Run the following command:

```bash
python calculator.py
